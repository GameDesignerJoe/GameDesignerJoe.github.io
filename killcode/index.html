// Signal Interpretation
Locked — correct key, correct position
Displaced — correct key, wrong position
Null — key not present in hash
Signals are counts only — they do not identify which slot triggered.
// Program Reference
MOLE — Leaks one colour confirmed present in the hash
GHOST — Reveals one colour definitively absent from the hash
PING — Scans for repeated keys in the hash structure
PROBE — Pick any slot + any key — confirms if correct there
BUFFER — Extends intrusion window by one cycle
ROOT — Decrypts one confirmed key+position pair

// LOCAL SERVER REQUIRED

kill.code uses ES modules — these can't load when the file is opened directly from disk (file://).

From the project root, run one of:

python -m http.server 8000
# or
npx serve .
