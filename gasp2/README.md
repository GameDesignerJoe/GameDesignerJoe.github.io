# GASP 2

Script → storyboard → video → sound, on your own PC. See `PLAN.md` for what's built and `CLAUDE.md` for how it's put together.

**First run (Windows):**
1. Pull the repo (or let GASP 1.0's launcher pull it).
2. Double-click `Create desktop shortcut.bat` in this folder. It puts **GASP 2** on your desktop.
3. Open GASP 2. Your keys from GASP 1.0 are picked up automatically; ⚙ Settings shows which ones it found.

Your stories, keyframes and videos live in `C:\Users\<you>\GASP Library`, outside the repo, so nothing you make goes to GitHub.
If something misbehaves, `GASP 2 (with log).bat` runs the same app with the server log visible.
